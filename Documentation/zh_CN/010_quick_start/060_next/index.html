    接下来读什么

    两条路线走完后，项目中已有一份可运行的结果。本页按"接下来想做什么"给出查阅入口，末尾附一份卡住时的排查顺序。

    战斗¶

    想做的东西 去哪
    加第二个敌人、换敌人动画 战斗系统 → 战斗初始化
    改战斗界面、按钮、状态栏 战斗系统 → UI
    改战斗框大小、挖洞、遮罩 战斗系统 → 战斗框
    换灵魂模式、做单向平台 战斗系统 → 玩家与灵魂
    改攻击校准、伤害公式、自定义武器 战斗系统 → 攻击模式
    敌人回合的完整写法 战斗系统 → 回合脚本
    放骨头、骨墙、追踪炮 战斗系统 → 弹幕库
    控制战斗流程、回调一览 战斗系统 → 战斗场景与回调

    主世界¶

    想做的东西 去哪
    场景骨架、图层、存档数据 Overworld → 初始化与场景骨架
    新建地图、对象层属性、调试 Overworld → 地图与对象层
    图块集、动画图块 Overworld → STI 与图块集
    玩家贴图、移动、朝向 Overworld → 角色
    切换场景、NPC 对话 Overworld → 交互与对话
    菜单、存档点、箱子 Overworld → 菜单 · 存档 · 箱子
    走路遇敌、接进战斗 Overworld → 遇敌
    商店买卖、交谈话题 Overworld → 商店

    图层顺序与增删 基础开发 → 图层系统
    背景音乐与音效 基础开发 → 音频

    遮罩、边框、画布与屏幕 基础开发 → 遮罩 / 边框 / 画布与屏幕
    菜单类界面控件 基础开发 → GUI 库

    卡住时的排查顺序¶

    1. 先看终端输出。 文件找不到、模块加载失败、贴图缺失都会打印带 [WARNING] 的行。Windows 下控制台默认开启。
    2. 按 F5 热重载。 清掉模块缓存并重进当前场景，改完代码不必重启游戏。改的是 conf_pure.lua 时按 F2 。
    3. 按 F6 打印环境信息。 输出当前场景名、贴图数、图层对象数，用于确认改动是否真的生效。
    4. 确认文件放对位置。 Game 区优先于引擎目录，两个根都找不到时才会报错。规则见 基础开发 → Game 区与资源覆盖 。
    5. 确认路径大小写。 图片路径在 Windows 上大小写不敏感，打包到 Android 或 Linux 之后会找不到该图。

    热键只在开发版生效

    F5 与 F6 需要 _RELEASED = false ，打包发布后失效。全部热键见 辅助开发 → 引擎热键 。

    不确定引擎自带了什么

    辅助开发 → 内置资源一览 列出了实际被引用的字体、音效与贴图。制作内容前先查该页，可以避免重复准备素材。
