    边框

    部分作品（例如 Undertale BNP ）除居中的游戏画面外，还带有一圈外边框。

    边框库位置： Scripts/Libraries/Utils/Border.lua

    两种形态（BORDER_MODE）¶

    conf.lua 用 BORDER_MODE 决定窗口使用哪一组尺寸， love.conf 中只做一次二选一：

    LOGICAL_WIDTH, LOGICAL_HEIGHT = 640, 480    -- BORDER_MODE 关闭时的窗口尺寸
BORDER_WIDTH,  BORDER_HEIGHT  = 960, 540    -- BORDER_MODE 开启时的窗口尺寸
BORDER_MODE = true

-- love.conf 内
t.window.width  = BORDER_MODE and BORDER_WIDTH  or LOGICAL_WIDTH
t.window.height = BORDER_MODE and BORDER_HEIGHT or LOGICAL_HEIGHT
    BORDER_MODE 窗口尺寸 画面摆放 画面四周
    false LOGICAL_WIDTH × LOGICAL_HEIGHT ，即 640×480 按 SCREEN_SCALE 缩放后放进窗口 不绘制边框图，只有一圈描边
    true （默认） BORDER_WIDTH × BORDER_HEIGHT ，即 960×540 放进边框图的开窗，默认开窗为居中的 640×480 区域，偏移 (160, 30) 未启用边框时只有一圈描边，启用后为边框图

    两种形态只改变窗口尺寸与摆放基准。画布始终是 CANVAS_WIDTH × CANVAS_HEIGHT ，游戏内坐标不受窗口尺寸影响，场景代码无需区分这两种情况。

    BORDER_MODE 只在启动时决定窗口大小，运行中修改该变量不会重建窗口。窗口尺寸运行时发生变化（例如 F4 全屏）时，引擎按当前窗口重新贴合边框图，画面与边框不会错位。

    描边占位¶

    BORDER_MODE = true 不等于已经绘制边框图。边框图需要 Border.enabled 为 true ，并且 Border.Draw 能取到图片（未调用过 SetImage 时自动使用 ruins ）。在此之前， main.lua 的 love.draw 在画面外围画一圈描边（颜色取自 MainColor ，默认白色）：

    if (BORDER_MODE) then
    Border.Draw()
end

SE.graphics.push()
SE.graphics.translate(DrawX, DrawY)
SE.graphics.scale(ScreenScale, ScreenScale)

SE.graphics.setColor(1, 1, 1, 1)
SE.graphics.draw(source)
if (BORDER_MODE and not Border.enabled) then
    local r, g, b = unpack(Global.GetVariable("MainColor") or {1, 1, 1})
    SE.graphics.setColor(r, g, b, 1)
    SE.graphics.setLineWidth(2)
    SE.graphics.rectangle("line", -1, -1, 642, 482)
    SE.graphics.setColor(1, 1, 1, 1)
end
SE.graphics.pop()

    默认启动后的画面：960×540 的窗口内，中间一块 640×480 的游戏画面，外围为边框图。未启用边框时画面外围是一圈 2px 描边，描边以外为黑底。这圈描边是边框尚未就位时的占位，不属于边框图，只有 Border.enabled 为 false 时才出现。

    可见状态由 Border.enabled 与 Border.alpha 共同决定：

    enabled alpha 画面
    false 任意值 描边
    true 大于 0 边框图
    true 0 无装饰

    main.lua 在启动时调用 Border.SetEnabled(true) 与 Border.FadeIn(0) ，并在 love.load 中用 Border.SetImage("snowy.png") 选定雪镇边框，因此默认画面是 960×540 窗口中间的 640×480 游戏画面，外围为边框图，开局约 1 秒淡入。FadeIn 的时长参数不为正数时按 1 秒处理，需要瞬时显示时用 Border.SetAlpha(1) 。想让画面回到描边状态，调用 Border.SetEnabled(false) 即可。

    描边跟随主色调

    描边的颜色取自 MainColor （见 conf_pure.lua ，默认 {1, 1, 1} ），与战斗框等元素保持一致。制作 Underfell 等 AU 时把主色调改为粉色，这圈描边会一起变色。

    Border.FadeOut 结束后会把 enabled 置为 false ，因此淡出完成即回到描边状态。需要在淡出后保持无装饰时，在淡出完成后调用一次 Border.SetEnabled(true) （此时 alpha 已为 0 ）。

    注册边框¶

    引擎预置七张边框图，位于 Resources/Sprites/Border/ ，尺寸均为 960×540 ，开窗位于 (160, 30) 、大小 640×480 ，与自动居中的计算结果一致：

    • idle 掌机外形边框，画面区带 1px 白线。
    • ruins 遗迹。
    • snowy 雪镇。
    • waterfall 瀑布。
    • hotland 热地。
    • newhome 新家。
    • truelab 真实验室。

    除 idle 外，六张区域边框取自原版 UNDERTALE PS4 版，按游戏区域划分；snowy 为引擎启动时的默认边框。

    使用 Border.RegisterImage(name, path) 注册边框，注册后通过 name 调用。

    • name 边框的代号。
    • path 边框的路径，从 Resources/Sprites/Border/ 文件夹开始算起。

    SetImage 也接受直接路径，未注册过的路径按原样加载：

    Border.RegisterImage("snow", "user/snow.png")
Border.SetImage("snow")

Border.SetImage("user/other.png")   -- 绕过注册，直接加载

    自制边框图需满足三项：与 BORDER_WIDTH × BORDER_HEIGHT 同比例，中间留出 640×480 的画面区，其余部分不透明。开窗不在正中时用 Border.SetOpening(x, y) 指定左上角坐标。

    启用边框¶

    Border.SetImage("ruins")    -- 选择边框图
Border.SetEnabled(true)     -- 启用，描边消失
Border.FadeIn(1)            -- 1 秒淡入

    Border.Draw 在 BORDER_MODE = false 时不会被调用，此时启用边框不会显示任何内容。

    其他函数

    • SetAlpha(a) 设置透明度，取值 0–1 ，淡入淡出均通过修改该值实现。
    • FadeOut(dur) 在 dur 秒内淡出，结束后自动 SetEnabled(false) 。
    • SetOpening(x, y) 手动指定开窗左上角的像素坐标，坐标以边框图左上角为原点。
    • GetOpening(imgW, imgH) 返回开窗相对边框图左上角的偏移。未手动设置过时按画布居中计算，即 ((图宽 − CANVAS_WIDTH) / 2, (图高 − CANVAS_HEIGHT) / 2) 。

    边框图与画布共用同一个 ScreenScale 与 DrawX / DrawY 偏移，因此缩放、全屏下均与画面同步。 BORDER_MODE = true 时 SCREEN_SCALE 贴合的是 BORDER_WIDTH × BORDER_HEIGHT ，而非画布尺寸，详见 画布与屏幕 。

    其他操作¶

    若需在边框区域绘制其他内容，可修改 Border.Draw 函数，其中只能使用 love2d 的官方绘制方法，详见 与LOVE开发 → 图像绘制 。
