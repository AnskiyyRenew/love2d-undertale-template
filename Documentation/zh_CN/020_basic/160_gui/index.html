    ❕️ GUI 库

    引擎自带的 UNDERTALE 风格图形界面库，提供窗口、文字、按钮、滑块、文本输入框、下拉框等组件，以及一个把鼠标坐标从窗口空间换算到画布空间的输入助手。

    库路径： Scripts/Libraries/GUI/ （文件夹形式， init.lua 为入口）。

    加载：在 main.lua 中 GUI = ImportFile("GUI")，必须在 Typers 之后（Label 包装了 Typers.InstText）。加载后即可在任意场景直接用全局 GUI 调用。

    依赖：

    • Typers —— Label / Button / Slider / TextInput / Dropdown 的文字都走 Typers.InstText，中英文自动分流。
    • 图层系统 —— 所有绘制经 Layers.add_external 注册，不建贴图。

    坐标与图层约定¶

    约定 说明
    坐标语义 左上角 (x, y) + 宽高 (w, h)；Window:SetCenter 切中心点（兼容战斗框语义）。
    默认图层 1000（高于战斗元素）；可用 :SetLayer 调整，或在 New 时传 layer。
    鼠标坐标 love 鼠标坐标是窗口屏幕空间，GUI 在 640×480 画布空间。两者经 GUI.Input.ScreenToCanvas 换算（见下文）。
    像素吸附 内部 math.floor(v + 0.5) 吸附，与 Sprites.snapCoord 一致。
    颜色还原 每次绘制完还原白色，颜色不会泄漏到同帧其他图层（陷阱 #7）。

    字体约定¶

    经实测，仅下列字号渲染清晰，GUI 库直接复用 Typers.InstText 的 bondfont 机制，调用方无需自行处理字体：

    语种 字体 字号
    英文 Resources/Fonts/determination_mono.ttf 27 或 13
    中文 Resources/Fonts/simsun.ttc 仅 13；画 27 号须 scale=2 放大

    中英混排由 Typers.InstText 按字符字节自动分流（charlen 判 1=英 / >1=中），GUI.Label 是它的薄封装。

    生命周期¶

    调用方持有组件引用，在 scene.clear 时逐个 :Destroy()。Layers.clear() 会停止 external 绘制，但不释放 Label 的 InstText 文本缓存引用（InstText 用引用计数），所以必须显式 Destroy，否则会泄漏并可能触发"Cannot use object after it has been released"。

    TextInput.Focus 会打开系统文本输入（love.keyboard.setTextInput）；Blur / Destroy 必须关闭它，否则离开场景后仍在接收输入。

    鼠标输入助手 GUI.Input¶

    关键点：love 的鼠标坐标是窗口屏幕空间的，GUI 组件在画布空间，必须换算才能命中。

    GUI.Input 用全局 DrawX / DrawY / ScreenScale（由 main.lua 的 updateScreenScale 设置）做换算，并做按键边沿检测，让场景每帧轮询 IsPressed / IsReleased / IsDown 即可，语义和键盘的手写 prev 表一致。

    状态模型：

    • held 实时—— OnPressed / OnReleased 直接改，IsDown 反映此刻状态。
    • pressed / released / wheel 每帧冻结——异步事件先进 pending，Update() 开头换入 state 并清 pending，所以 IsPressed / IsReleased 恰好为下一帧 true。

    场景接线（main.lua 已把全部鼠标回调转发到场景，非 pausing 时）：

    -- 四个 love 回调转发给助手
function scene.mousepressed(x, y, button)  GUI.Input.OnPressed(x, y, button) end
function scene.mousereleased(x, y, button) GUI.Input.OnReleased(x, y, button) end
function scene.mousemoved(x, y)            GUI.Input.OnMoved(x, y) end
function scene.wheelmoved(x, y)            GUI.Input.OnWheel(x, y) end

function scene.update(dt)
    GUI.Input.Update()   -- 必须放在 scene.update 最前面，冻结本帧状态

    local mx, my = GUI.Input.GetCanvasMouse()   -- 画布空间坐标
    if (GUI.Input.IsPressed(1)) then            -- 左键 = 1；本帧刚按下
        -- 命中检测 / 触发组件
    end
    local wheel = GUI.Input.GetWheel()          -- +1 上 / -1 下 / 0
end
    GUI.Input 接口一览
    • ScreenToCanvas(sx, sy) 纯换算：(sx-DrawX)/ScreenScale, (sy-DrawY)/ScreenScale。
    • GetCanvasMouse() 当前画布空间光标位置。
    • IsDown(button) 是否按住（实时）。
    • IsPressed(button) 本帧是否刚按下（边沿）。
    • IsReleased(button) 本帧是否刚松开（边沿）。
    • GetWheel() 本帧滚轮增量（+1 / -1 / 0）。
    • OnPressed(sx, sy, btn) / OnReleased(...) / OnMoved(sx, sy) / OnWheel(x, y) 在 love 回调里调。
    • Update() 在 scene.update 开头调。
    • Reset() 在 scene.clear 调——防鼠标按下后切场景，love 可能不给新场景发 mousereleased 导致 IsDown 卡死。

    组件¶

    Window¶

    视觉窗口：两个矩形堆叠（粗外边框 + 内填充），纯视觉、无碰撞、无玩家约束。动画用和战斗框一样的"限速逼近目标"方式（smooth_value）。

    local win = GUI.Window.New{
    x = 200, y = 100, w = 240, h = 120,
    thickness = 5, layer = 1000,
}
win:ResizeWithSpeed(300, 150, 15, 15)   -- 平滑缩放（须在 scene.update 调 win:Update(dt)）
win:SetCenter(320, 240)                 -- 切中心点语义
win:SetVisible(false)
-- scene.clear: win:Destroy()
    Window 接口
    • New{x, y, w, h, thickness, outer, inner, layer, visible} 外层色默认 MainColor，内层默认黑。
    • :MoveTo(x, y, imm) / :SetCenter(cx, cy, imm) 移动；imm=true 立即同步不动画。
    • :Resize(w, h, imm) / :ResizeWithSpeed(w, h, sw, sh) 缩放。
    • :SetThickness(t, imm) 边框厚度。
    • :SetOuterColor(c) / :SetInnerColor(c) / :SetOuterAlpha(a) / :SetInnerAlpha(a)。
    • :SetVisible(v) / :SetLayer(layer)。
    • :Update(dt) 平滑动画驱动（静态菜单可不调）。
    • :GetCenter() / :ContainsPoint(x, y) 中心点 / 命中检测。
    • :Destroy() 幂等。

    Label¶

    文字标签，薄封装 Typers.InstText，中英文混排自动分流。

    local lbl = GUI.Label.New("Hello 世界", {320, 200})
lbl:SetAlign("center")
lbl:SetText("新文字")
lbl:SetColor(1, 1, 0)     -- 黄
lbl:SetAlpha(0.5)
lbl:SetWrapWidth(200)     -- 自动换行（传 nil/0 关闭）
-- scene.clear: lbl:Destroy()
    Label 接口
    • New(text, pos, layer, size) pos={x,y}；size={boxWidth,_} 开自动换行。
    • :SetText(t) / :SetAlign(mode) （"left" / "center" / "right"）/ :SetColor(r,g,b) / :SetAlpha(a)。
    • :SetPosition(x, y) / :SetWrapWidth(w) （改宽度后内部自动 Rebuild）/ :Rebuild()。
    • :Inst() 直接取底层 InstText（高级用途，慎用）。

    改 auto_wrap / size 不会自动重排

    InstText 的 auto_wrap 和 size 改了之后必须 :Rebuild()，否则行不会重排。Label.SetWrapWidth 内部已调，直接改 inst.auto_wrap 则要手动 Rebuild。

    Button¶

    按钮，UNDERTALE 风格选中态。键盘选中 = 前缀 "> " + 黄色；鼠标 hover = 黄色无前缀（两种状态视觉区分开）；未选中用 2 空格等宽占位防文字抖动。

    local btn = GUI.Button.New{
    x = 200, y = 150, text = "FIGHT",
    w = 200, h = 30,            -- 鼠标命中区
    onSelect = function() end,
}
btn:SetSelected(true)          -- 键盘选中
btn:SetHovered(true)           -- 鼠标 hover
if (confirm) then btn:Trigger() end
    Button 接口
    • New{x, y, w, h, text, selected, onSelect, layer, prefix, pad, colorNormal, colorSelected}。
    • :SetSelected(v) / :SetHovered(v) / :SetText(t) / :SetPosition(x, y) / :SetOnSelect(fn)。
    • :ContainsPoint(x, y) 命中检测。
    • :Trigger() 触发 onSelect 回调。
    • 颜色逻辑：selected or hovered → colorSelected（黄），否则 colorNormal（白）。

    Slider¶

    水平滑块：track + knob 两矩形。纯组件不读输入，场景调 :Move / :SetValue / :DragTo / :Wheel 驱动。

    local s = GUI.Slider.New{
    x = 200, y = 300, w = 240,
    min = 0, max = 100, value = 50, step = 1,
    focused = true,             -- knob 变黄
}
-- 键盘：:Move(1) / :Move(-1)
-- 鼠标：:DragTo(mx, my) 拖拽 / :Wheel(dir) 滚轮 / :ContainsPoint 命中
local v = s:GetValue()
    Slider 接口
    • New{x, y, w, min, max, value, step, trackH, knobSize, trackColor, knobColor, focusedColor, focused, showLabel, layer}。
    • :Move(dir) +1 / -1 个 step；:SetValue(v) / :SetRange(min, max) / :GetValue()。
    • :DragTo(cx, cy) 画布空间 x → value（拖拽时调）。
    • :Wheel(dir) 滚轮（同 :Move）。
    • :SetFocused(v) knob 高亮。
    • :ContainsPoint(x, y) 命中（带 4px 余量）。
    • step 网格吸附防连续 Move 的浮点漂移。

    TextInput¶

    单行文本输入框：窗口式细边框 + 文字 + 闪烁光标。Focus 打开系统文本输入（love.keyboard.setTextInput），让 OS 发字符事件；场景把 textinput / keypressed 路由进来。

    local ti = GUI.TextInput.New{
    x = 200, y = 100, w = 240, h = 32,
    placeholder = "Name", maxLen = 16,
    onSubmit = function(self) print(self:GetText()) end,
}
-- 场景路由：
--   scene.textinput(t)  -> ti:HandleTextInput(t)
--   scene.keypressed(k) -> ti:HandleKeyPressed(k)
--   scene.update(dt)    -> ti:Update(dt)        -- 光标闪烁
-- 点击聚焦：if (ti:ContainsPoint(mx,my)) then ti:Focus() else ti:Blur() end
    TextInput 接口
    • New{x, y, w, h, thickness, placeholder, maxLen, layer, onSubmit}。
    • :Focus() / :Blur() / :SetFocused(v) —— 开关系统文本输入 + setKeyRepeat（backspace 长按重复）。
    • :HandleTextInput(text) 追加字符（滤换行，按 maxLen 截断）。
    • :HandleKeyPressed(key) 返回是否消费：backspace 删一个 UTF-8 码点、escape blur、return / kpenter 触发 onSubmit；其他键返回 false（不消费，键盘导航照常工作）。
    • :SetText(t) / :GetText() / :ContainsPoint(x, y) / :Update(dt) / :SetPosition(x, y)。

    maxLen 按字符数计，不按字节

    maxLen 数 UTF-8 码点，所以一个 CJK 字算 1。backspace 也删一个码点（不是一字节）。

    Dropdown¶

    下拉框：触发按钮显示当前选中项，点击展开选项列表。w 是菜单宽度，buttonW（可选，默认=w）是触发按钮宽度。expand="up"|"down" 指定展开方向。

    local dd = GUI.Dropdown.New{
    x = 200, y = 200, w = 180,
    buttonW = 180,            -- 可选，默认 = w
    buttonH = 24, itemH = 24,
    items = {"Red", "Green", "Blue"},
    selected = 1,
    expand = "down",          -- "up" | "down"
    layer = 1001,
    onSelect = function(self, idx, text) print(idx, text) end,
}
-- 场景路由（scene.update，GUI.Input.Update() 之后）：
local mx, my = GUI.Input.GetCanvasMouse()
dd:SetHover(mx, my)
if (GUI.Input.IsPressed(1)) then
    local consumed = dd:HandleClick(mx, my)  -- 点触发按钮=展开/收起；点选项=选中+收起；点外部=收起但不消费
end
    Dropdown 接口
    • New{x, y, w, buttonW, buttonH, itemH, thickness, gap, expand, items, selected, layer, onSelect}。
    • :SetHover(mx, my) 每帧调，更新 hover 高亮。
    • :HandleClick(mx, my) 点击时调，返回是否消费。
    • :SetExpanded(v) / :IsExpanded() / :GetSelected() / :GetSelectedText() / :SetItems(items) / :SetPosition(x, y) / :SetOnSelect(fn) / :ContainsAny(mx, my)。
    • 选中项 = 黄 + 前缀 "> "；hover 项 = 黄无前缀；其他 = 白（与 Button 一致）。
    • 触发按钮边框 hover / 展开时变黄；菜单边框始终白。
    • 菜单左对齐触发按钮；选项行位置 New 时定，展开只切 alpha=0/1。

    陷阱¶

    图层同层遮挡：背景不能与文字同层

    Layers 同层按 _id（注册顺序）排，后注册的后画（视觉在上）。若一个组件的背景（drawWindow 黑色内层）和文字 Label 同层，且背景后注册，黑色填充会盖住文字。

    解决：组件内部把背景放 layer、文字放 layer+1（光标再 layer+2）。TextInput 和 Dropdown 都这么做。

    闭包引用 local 必须先声明

    若一个组件的 onSubmit / onSelect 等回调闭包引用了某个 local 变量（如 feedback_timer），而该 local 声明在闭包之后，闭包会写全局而非那个 local（Lua 不会提升 local）。

    -- 错：onSubmit 闭包写的是全局 feedback_timer，不是下面的 local
local ti = GUI.TextInput.New{ onSubmit = function() feedback_timer = 120 end }
local feedback_timer = 0

-- 对：local 提到闭包之前
local feedback_timer = 0
local ti = GUI.TextInput.New{ onSubmit = function() feedback_timer = 120 end }

    luac -p 查不出这个（运行时作用域问题，不是语法错）。
