    Lua 速通

    本篇其实并不适合新手入门，更像是随着后续开发进行查阅的手册。
    后续会有多个文件重新超链接到此页面。

    变量（Variable）¶

    这将是在开发过程中最常打交道的一个物体。
    简单来说，绝大部分 .lua 作为后缀的文件，其内部都拥有变量

    变量举例

    a = 10          -- 单个字母
abb = ""        -- 多个字母
_count = 0      -- 下划线开头
playerHP = 20   -- 驼峰命名

    以上这些例子都是 变量 。

    命名规范（必须遵守）¶

    1. 变量不允许用关键词命名（如 if ， end 等）
    2. 变量不允许用数字开头命名（如 1var 等）
    3. 引擎里统一用 ASCII（英文字母、数字、下划线）命名

    中文到底能不能当变量名？¶

    能，但强烈不建议。

    SoulEngine 跑在 LuaJIT 上（LÖVE 12 自带），而 LuaJIT 的词法分析器把 0x80 以上的字节也当作合法标识符字符，所以下面这段在游戏里真的能跑：

    你好 = ""
你好 = "hello"
print(你好)          -- hello

function 打招呼() return "hi" end
print(打招呼())      -- hi

local t = {名字 = "Chara"}
print(t.名字)        -- Chara

    换一个 Lua 解释器就爆炸

    标准 Lua 5.1（PUC）会直接拒绝上面那些写法：

    lua.exe: t.lua:1: unexpected symbol near 'ä'

    而引擎仓库里的 verify_*.lua 校验脚本、部分构建/导出流程用的就是标准 Lua。 一源两跑，中文标识符那一半会在另一条路上突然语法报错，而且报错位置指向的是字节而不是你写的字。

    所以统一写 ASCII

    中文不是不能用，而是只能放在字符串里（以及给 Tiled 图层名、注释这些"给人和别的工具看"的地方）：

    local greeting = "你好"      -- ✅ 字符串里随便写
local name = "Chara"          -- ✅ 变量名用 ASCII

    引擎内部所有变量、函数、表字段一律 ASCII，跟着写不会有任何问题。

    常见类型¶

    1. 数字： 1, 2, 3
    2. 字符串（也可以称作文本）："hello", "我是一个完整的句子。", "滚木"
    3. 表，功能最强大的变量（可以同时被看做是数组或字典）：{1, 2, 3, 4}
    4. 布尔值（想象成一个开关）：true, false
    5. 函数（不是数学上的！通过在句末加括号来使用）：cool()

    关键词（Keyword）¶

    变量也分 三六九等 ，虽然并不是严格意义上的，但是 如果你打了一个特殊的单词，那么这个词可能会带有高亮标注效果，表明这个词是关键词。

    下面让我们看一些简单的例子和对比：

    关键词与非关键词

    if then while for do end elseif else in

    IF aaa time var1 incredible

    注：我并没有让其强行变色，而是被识别出关键词高亮所致。
    下面给出混合版本：

    关键词高亮

    if time == a then
end

    总结：在起名时避开这些关键词。

    常用组合搭配¶

    在这里，我们不会讲太复杂的代码块，只给出最常用的几个：

    1.条件判断：若某个值达成条件，执行某操作。

    if语句

    if time == 60 then
    a = a + 1
end

    上面语句执行：当 time 等于 60 的时候，执行由 if - end 包裹的内容。（比如这里就是a增大了1）

    2.if链：通过不断匹配每一个条件来确定最终符合的分支：

    if链

    if     time == 60 then
                        分支一
elseif time == 90 then
                        分支二
elseif time == 95 then
                        分支三
else
                        最终分支
end

    上面语句执行：当 time 等于 60、90、95 时。分别进入分支一、二、三中。
    若都不符合，则进入由 else 管理的最终分支中。

    3.循环执行：用一个抽象的数循环执行某操作：

    正常for循环

    for i = 1, 10, 1
do
    a = a + 1
end

    上面语句执行：新创一个 i 变量，让其从 1 开始 每次增大1 直到 10 。
    在此期间每次加1都会执行一次 for - end 包裹的内容。

    简单来说，运行了十次。

    更有力气的循环：

    while循环

    while i < 10
do
    i = i + 1
end

    上面语句执行：检测到 i 小于10， 不断地 执行 i = i + 1 操作， 直到 i 不符合条件为止。

    短路选择¶

    or 的基本语义¶

    如果 a 存在或者为真，那么选择 a ；反之选择 b 。
    通过这种方法，我们可以制作出默认值替换的效果。

    格式如下： 

    var = a or b

    示例

    若test没有填写参数，那么会默认使用 or 之后的内容，在这个例子中为 default output. 。 

    local function test(b)
    print(b or "default output.")
end
test()

    and or 条件判断¶

    若条件 a 为真，那么使用 b ，否则使用 c 。
    通过这种方法，我们可以只使用一行完成二元或多元选择。

    格式如下： 

    var = a and b or c

    这个操作比较吃逻辑和括号的处理。

    常见于划定战斗框大小最小为 16 的情况：

    示例

    如果 width 大于 16 ，那么使用 width ，否则使用 16 。`

    local _width = (width > 16) and width or 16

    嵌套操作

    每一层都是一个关口， cfg 、 cfg.db 、 cfg.db.host 这三个变量中，只要有一个不符合标准就会强制输出 localhost 。

    local config = {
    db = { host = "127.0.0.1" }
}

local function getHost(cfg)
    return (cfg and cfg.db and cfg.db.host) or "localhost"
end

print(getHost(config))                        -- 127.0.0.1
print(getHost({ db = {} }))                   -- localhost
print(getHost(nil))                           -- localhost
