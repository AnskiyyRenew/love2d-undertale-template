# Update Log

> Changes since tag `v3.0.1-stable` (`56b162d`) — to be used as the release note for the next build.

## New Features

- Stencil (mask) and shader support in all four typer modules, with one implementation in `Scripts/Libraries/Typers/render.lua`: `typer:SetStencils({mask})`, `typer:SetShaders({shader})`, `GetStencils` / `GetShaders`, `ClearStencils` / `ClearShaders`, `AddShader` / `RemoveShader`. Both are optional and free while unset.
- The typer shader pass bakes the text block into an offscreen canvas before running the chain, so `tex_coords` covers 0..1 instead of font-atlas UVs and shaders written for sprites behave identically on text. Canvases are cached in 32 px steps (up to 12 sizes); masks are applied after the shader pass.
- `timers.runFrame(func, interval, count, immediate)` and `timers.runSecond(...)` accept an `immediate` flag that fires `func` once at creation and counts it toward `count`.
- Added `Scripts/Shaders/RGBOffset.glsl`: an RGB split with independent `r_offset` / `g_offset` / `b_offset` pixel offsets (converted to UV through `tex_size`). Out-of-texture samples count as empty instead of repeating the edge, and alpha is the union of the three samples.
- Added a host-channel option to the ShaderToy converter: `shadertoy.convert(code, { hostChannel = 0 })` (numeric shorthand allowed) rewrites `texture(iChannel0, uv)` into a read of the sprite's own texture, y-flipped to match `texture_coords`. `hostFlipY = false` disables the flip, `hostChannels = {0, 1}` binds several channels. Host channels allocate no texture slot; without the option the generated GLSL is unchanged.
- Added `Scripts/Libraries/Engine/DevMode.lua`, an in-game developer mode with a wave picker. Typing `e` `n` `d` (1.5 s apart, no modifier, not while a text field has focus) unlocks it, the sequence again locks it, `F10` toggles the panel. The list is the real `Game/Waves/` and `Scripts/Waves/` tree, so `Game/Waves/bones/wave1.lua` appears as `bones.wave1` — the same string an encounter's `wave` field takes. Folders expand, the list scrolls, keyboard navigation mirrors the mouse, and the scene is paused through `scene.pausing` while the panel is open. `S` ends the enemy turn, `I` toggles invincible. Not loaded when `_RELEASED = true`.
- Every DevMode string is localized through `Localize.localizeText` under `DevMode.*` keys added to the engine's `Localization/en.json` and `Localization/zh_CN.json`, looked up at call time so an F2 language reload takes effect immediately. A game can override single keys from `Game/Localization/<lang>.json`.
- Added `Battle.DebugJumpWave(wave_name)` and `Battle.DebugEndWave()` to `Scripts/Libraries/Battle/init.lua` (no-ops returning `false` in a release build). A jump reuses the normal transitions: `EndWave()` on the running wave, cache drop, arena restore, then `ChangeState("DEFENDING")` so the target file's top-level code runs again. `Battle.Waves.ENDED` is reset so a leftover `true` cannot end the next wave.
- Added `Scripts/Scenes/TEST/scene_typerfx.lua` (typer mask / shader checks: baseline, mask only, shader only, both, animated `Wave` over an `EText`) and `Scripts/Scenes/TEST/scene_shader_host.lua` (converted shader sampling the host texture — a solid red screen means the channel reads the sprite, not an external image). Point `FirstRoom` at them to run.
- Added a one-click runtime installer under `Packager/setup/`: `install.bat` and `install.sh` download LOVE 12.0 into `Packager/tools/love` — no system directory, no `PATH` edit, deleting the folder is the uninstall. 12.0 has no tagged release, so `setup.conf` points at the love2d/love CI artifacts through nightly.link; URLs, destination and cache path are `KEY=VALUE` lines in that one file. Official artifacts are zip-in-zip and are unwrapped until `love.exe` appears. Flags: `-Check`, `-Force`, `-Dest`, `-Url`, `--platform linux|macos`; output is English on purpose, because code page 936 mangles Chinese coming out of a `.ps1`.
- Added `Packager/setup/bootstrap.bat` / `bootstrap.sh` for a machine that has neither the repository nor LOVE: clone `--depth 1` by default, fall back to the `codeload` zip when git is missing, refuse a non-empty target without `conf.lua`, then hand over to that checkout's installer. Flags: `-Dir`, `-Update`, `-Zip`, `-Full`, `-SkipLOVE`.
- Added `Packager/play.bat` and `Packager/play.sh`, which start the game with the portable runtime, looking at `SE_LOVE`, then `Packager/tools/love`, then `PATH`, and forward extra arguments to LOVE. `play.bat` prefers `lovec.exe` so `print` output stays visible; `play.sh` also probes the AppImage and macOS bundle layouts.
- `Blasters` instances accept a private `Step(dt)` hook, called at the end of each frame's shared update with the blaster as `self`, so per-blaster behaviour (custom aim, extra beams, movement) needs no fork of the library. `blasters.Update` is annotated with what the shared pass already does.
- `blaster:OnFrame(frame, fn)` and `blaster:During(from_frame, to_frame, fn)` register frame-indexed callbacks on a blaster, numbered like `time` (the first update is 1). One-shots fire once and still fire if their frame has already passed; ranges include both ends and take a nil end frame to run until destruction. Both run after the shared pass and before `Step`, in registration order, and may fire beams or destroy the blaster. `Destroy` is now idempotent, and the `NewTween` variant also destroys its beams.
- Both callbacks also accept a phase name in place of a frame: `OnFrame("Firing", fn)` uses the phase's first frame, `During("Firing", fn)` the whole window. `Waiting` / `Charging` / `Firing` / `Fading` are case-insensitive and resolved per blaster from `wait_time` and the new `blaster.fire_total`, which keeps the construction-time `fire_time`. `Charging` clamps to frame 1 when `wait_time <= 12`, `Fading` ends at destruction, and a beam-less blaster never reaches it.
- Five more frames ship in `Resources/Sprites/Border/` and are registered as presets: `snowy`, `waterfall`, `hotland`, `newhome` and `truelab`, the original UNDERTALE PS4 area borders. All are 960×540 with the same centered 640×480 opening at `(160, 30)` as `ruins` and `idle`, so they need no `SetOpening` call.

## Bug Fixes

- Fixed the Windows fused exe losing the project's native DLLs at runtime. The packager now copies every `.dll` in the project next to the exe and mirrors each at its original relative path, so `ffi.load` and `require("https")` find `https.dll`, `discord-rpc-x64.dll` and PerfectPixel's `cpp.dll`. Name clashes keep the LÖVE runtime version, an x86/x64 pair keeps x64, and each collision is logged. `secrets.dll` keeps its dedicated copier so an unbuilt library still warns.
- Fixed the wave picker reporting "not in a battle" when the project's `Battle` predates the debug entry points. The state test now only answers the state question, and a missing `DebugJumpWave` is checked right before use and reported as "this project's Battle has no DebugJumpWave; sync `Battle/init.lua`". `DebugEndWave` behind `S` gets the same treatment.
- Fixed `dt` never reaching the battle turn: `ui.Update(dt)` called `state.Update()` without forwarding the delta, so `Battle._wave.Update(dt)`, `Battle.attack.Update(dt)` and `Battle.FleeUpdate(dt)` all received `nil`. Any wave code reading `dt` — a shader `update`, a timer, movement integration — ran on `nil`. The delta is now forwarded in all three states.
- Removed the only Lua 5.2+ syntax in the engine: `Tween.Update` used four `goto continue` jumps and a `::continue::` label, which made `check_compat.py --strict 3` report six blocking errors. It now dispatches through `if` / `elseif` / `else` with unchanged ordering, removal points and `time` increments, and the file is pure ASCII.
- Fixed the borderless outline ignoring `MainColor`: it was always white, and in non-`BORDER_MODE` builds it fell outside the 640x480 window. It now takes `MainColor` and is drawn only under `BORDER_MODE`.

## Partial Changes

- `_VER` in `conf.lua` bumped to `3.0.2-stable`, with `_INFO.TITLE` aligned to `v3.0.2`.
- The template now boots into the bordered window: `BORDER_MODE` defaults to `true`, and `main.lua` enables the border and opens with the `snowy` frame, so the 2px outline is only the fallback for a game that turns the border off.
- `scenes.switchTo` resets the camera, so a scene that moved it cannot leave the offset behind for the next one.
- The four typer modules route their draw through `render.draw(emit, bounds, stencils, shaders)` instead of each carrying its own letter loop; emitted draw calls are unchanged when neither a mask nor a shader is set.
- `masks.New`'s `image` parameter is annotated as nullable (`love.Image|table|nil`).
- Comments across the whole Lua tree are now EmmyLua only and English only, in two passes: a `---` summary per file, `---@param` / `---@return` above documented functions, and nothing else. The second pass covered the remaining 127 Lua files and the uniforms of all 8 shaders (net −950 lines, including 316 `FuncProtector.lua` TODO placeholders); `main.lua` and both `conf_pure.lua` keep plain `--` section headers because they are flat config lists rather than APIs. Code untouched — `luac -p`, a comment-stripped token diff against `HEAD` and `check_compat.py --strict 3` all clean. Vendored ports (STI, sock, binser, bitser, dkjson, MD5, PerfectPixel, ShaderToy) and the generated `Engine/_FuncList.lua` are left alone.
- `love.conf` in `conf.lua` gained one English note per setting, trailing and aligned to a fixed column, and a `---@` follow-up corrected three annotations (`discord.timestamp` takes `number|nil`, `luaextended.printTable` has no return, `safejson.encode` returns `string|boolean`).
- `Scripts/Scenes/TOOL/event.lua` removed: it was a whole file wrapped in `--[[ ]]`, its content long superseded by the real scene modules.
- `Packager/tools/` (portable runtime plus download cache, about 14 MB per platform) is in `.gitignore`, so the one-click setup leaves the working tree clean.
- The packager always excludes `Export/`, `Packager/` and `soulengine-doc3/` from the game payload (`.love`, exe, Android, Web), so the love-android template can no longer leak into an archive; the "exclude tool folder" checkbox now only affects the source backup, and the same set feeds the DLL copier. A locally installed `Packager/tools/love-js` fills the love.js command automatically (`-c -t <title> -m 134217728`), documented in `Packager/README.md`.
- Added `.gitattributes` with `*.sh text eol=lf`, so the setup and play scripts survive being copied to Linux or macOS from a Windows clone. Every `.sh` already used LF; `.bat` is left alone because the repository stores it with LF and cmd reads it fine.
- `README.md` in both languages and `Packager/README.md` put the one-click route first: entry point per OS in one table, what the scripts deliberately do not touch, the bootstrap flags, how to repoint the download source, dependencies per platform. The `Packager/` listing gains `play.bat` / `play.sh`, `setup/` and `tools/love/`.
- The ending scene plays `mus_lastgoodbye.ogg` instead of `End.ogg`, and `Resources/Music/End.ogg` is removed; the credits line that named it becomes `lb.ogg made by Toby Fox`.
- Discord Rich Presence set up by `main.lua` advertises the template rather than the test encounter: `large_image` `qq20250220-225345` → `icon`, `large_text` `It's a bad time.` → `SoulEngine`.

- `Scripts/Waves/_template.lua` drops the commented-out `if (time == 680) then -- EndWave() end` block, so the template no longer hints at a disabled ending point that has to be deleted first.
